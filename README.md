## 최종 통합 핸드오프 (가이드 Prompt 9)
| 항목 | 내용 |
|---|---|
| gameId | `solidarity` |
| 실행 진입점 | `solidarity/index.html` |
| COMMON_BASE | `'../shared/ethicity-elementary-common-v1'` (게임 폴더가 repo 루트에 있을 때) |
| 게임 유형 | 일반 미니게임(지도 위 끌어다 놓기·실시간 라운드). 탐험형 걷기 이동은 없음 |
| 논리 화면 | 지도 1280×720 (종횡비 유지 축소, 픽셀 렌더링) |
| 저장 키 | `ethicity.solidarity.save`, `ethicity.solidarity.sound` |
| CSS 범위 | `game.css` 전체가 `.game-solidarity` 아래로 한정. `--ee-*` 토큰·`.ee-*` 컴포넌트는 재정의하지 않음 |

**제출 파일**: `solidarity/index.html`, `solidarity/game.css`, `solidarity/game.js`, `solidarity/assets/residents.png`, `solidarity/assets/buildings.png`, `solidarity/assets/game-icons.png`

**공통 팩 의존 ID**
- character: `jiho` 또는 `haneul`(플레이어 선택), `saebom`, `daon`, `robot` — 지도는 walk 시트(4방향 걷기 애니메이션), 대화·카드는 같은 ID의 portraits
- expression: `neutral`, `happy`, `worried`, `explaining`
- props: `tree`, `shrub`, `bench` (마을 지도 꾸미기)
- icon: `person`, `help`, `music`, `volume`, `inspect`
- effect: `correct`(경보 전달 성공), `clue`(마을방송), `retry`(물이 먼저 들어옴)
- sound: `door`, `tap`, `collect`, `paper`, `win`, `miss` — 효과음은 사용자가 켤 때만 재생(기본 꺼짐), BGM 없음
- UI: `.ee-theme`, `.ee-panel`, `.ee-speech`, `.ee-speaker`, `.ee-button`(+`.secondary`), `.ee-choice`(aria-pressed), `.ee-badge`, `.ee-notice`, `.ee-success`, Ethicity(Galmuri11) 글꼴

**통합 이벤트(postMessage)**
```js
{ type: 'ethicity:ready',    gameId: 'solidarity' }
{ type: 'ethicity:progress', gameId: 'solidarity', current: 1~6, total: 6 }  // 1R, 회의1, 2R, 회의2, 3R, 생각정리
{ type: 'ethicity:complete', gameId: 'solidarity', result: { completed: true } } // 엔딩 도달 시
```
result에는 학번·이름·자유입력을 넣지 않습니다. progress는 커지는 방향으로만, complete는 한 판에 한 번만 보냅니다(엔딩 화면을 다시 열거나 이어하기해도 중복 전송 없음).

## 가이드와 다르게 둔 것 (팀 공유 필요)
1. **학번·이름 입력**: 가이드는 실명 입력을 피하도록 하지만, 수업 제출용 PDF 때문에 유지했습니다. 이 기기의 PDF 파일과 브라우저 저장에만 쓰이고 통합 이벤트로는 보내지 않습니다. 팀에서 별명으로 통일하자고 하면 시작 화면만 바꾸면 됩니다.
2. **인물 이름 변경**: 이전 버전의 '민서'는 공식 캐릭터 **새봄**(수어 가능)으로, '나'는 **지호/하늘 중 선택**으로 바꿨습니다. 다온은 그대로 공식 캐릭터 다온입니다.
3. **대상 학년**: 공통 팩은 초등용이지만 이 게임은 고1 통합과학2 수업용 내용 수준을 유지했습니다.

| 2 장마 | 56초 | 돌발 ① 망설이는 어르신: 마을방송·이장 전화만 받은 어르신은 혼자 나서지 못함 → 봉사단이 직접 가거나 이웃 짝꿍이 있어야 출발 / 돌발 ② 22초에 길이 잠겨 봉사단 걸음이 느려짐 |
| 3 다음 여름 | 50초 | 망설이는 어르신이 그대로 적용 → '이웃 짝꿍 제도'가 없으면 어르신이 남음 |
- 잘 협력하면(1·2라운드 봉사단 배치 + 다국어·불빛·이장 연락망·이웃 짝꿍) 세 라운드 모두 100% 대피가 가능하도록 자동 플레이로 확인했습니다. 가장 먼저 잠기는 강변 어르신 집은 여유가 1초 안팎이라, 처음부터 서둘러야 합니다.
- '망설이는 어르신'은 2차 회의의 주민 목소리("전화가 와도 혼자 나가기 무서워")와 이어져, 기술 경보만으로는 부족하고 사람의 연결(이웃 짝꿍)이 필요하다는 점을 체험하게 합니다.

## 추가 기능 (2026.10.31 저녁)

- **교사용 시연 모드**: 주소 끝에 `?demo`를 붙여 엽니다(예: `solidarity-real/index.html?demo`). 학번·이름이 자동으로 채워지고, 기록을 저장하지 않으며 통합 이벤트도 보내지 않습니다. 위쪽의 ⏩ 버튼은 3배속, ⏭ 버튼은 라운드 바로 끝내기입니다.
- **라운드 결과의 '늦은 집' 표시**: 모두 대피하지 못한 라운드에서는 결과 창에 「지도에서 늦은 집 보기」 버튼이 나옵니다. 물이 먼저 닿은 집에 빨간 테두리가 깜빡이고, 「결과로 돌아가기」로 결과 창에 돌아옵니다.
- **상태 표시 위치**: '대피 ✓'·'구조 대기' 같은 표시를 집 위가 아닌 집 바로 아래에 붙였습니다. 실감판은 진한 색 이름표 모양으로 바꿨고, 경보를 받은 집 아래에는 노란 원 대신 은은한 빛이 깔립니다.
